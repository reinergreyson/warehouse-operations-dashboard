# Warehouse Operations Dashboard

An interactive dashboard that demonstrates how warehouse operations data can be used to monitor productivity, track operational issues, and support data-informed decisions.

**Live Demo:** https://reinergreyson.github.io/warehouse-operations-dashboard/

## Project Overview

This project simulates a warehouse operations environment using fictional data. It provides a visual summary of production performance, target attainment, unresolved incidents, and inventory discrepancies.

The dashboard was designed as a portfolio project to demonstrate practical skills in data visualization, operational reporting, and front-end development.

## Features

- **Key Performance Indicators (KPIs):** Displays units processed, target attainment, open incidents, and unresolved inventory discrepancies.
- **Productivity Visualization:** Compares actual output with modeled production targets.
- **Interactive Filters:** Filters results by department, reporting period, and issue status.
- **Issue Tracking:** Displays example operational and inventory issues with priority and status.
- **Operations Summary:** Generates a summary of performance and outstanding issues based on the selected filters.
- **Responsive Layout:** Adapts to desktop and smaller screen sizes.
- **Reset Functionality:** Restores the default dashboard filters.

## Data and Limitations

All data is fictional and intended for demonstration purposes only. No confidential company information or actual Walmart operational data is used.

The initial dataset contains seven days of sample productivity observations for four departments. The 14-day and 30-day views are illustrative projections based on the seven-day sample, not actual historical records. Issue records are a separate fictional sample.
